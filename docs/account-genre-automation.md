# アカウント別ジャンル自動投稿

各Threadsアカウントは1つ以上の楽天ジャンルIDと運用モードを持つ。既存アカウントの単一ジャンルは配列へ自動移行され、新規アカウントの既定モードは安全側の `semi_auto` とする。

## 予約時刻の処理

1. Dispatcherが有効なスケジュールを排他的に取得する。
2. 投稿セットIDを基に、アカウントで選択したジャンルから1つを安定して振り分け、その楽天ジャンルIDでランキングAPIを呼ぶ。再試行時も同じジャンルを使用する。
3. 商品条件とアカウント別または共通の戦略配分で候補を評価する。
4. 同一アカウントで過去30日以内に使った商品を可能な限り避ける。
5. 有効な投稿テンプレートを展開する。テンプレートがなければPR表記を含む既定文を使う。
6. 投稿本文と、アフィリエイトURLを含む返信をPostSetへ保存する。

## 運用モード

- `semi_auto`: 商品選定と文章作成まで自動。投稿管理で内容を確認し、「承認して投稿」を押したときだけThreadsへ公開する。
- `auto`: 商品選定と文章作成を自動化し、安全設定がすべて有効な場合だけThreadsへ公開する。条件不足時は承認待ちへフォールバックする。

## 安全条件

自動公開には、アカウントが稼働中で、Dry Runが無効、本番投稿許可が有効、自動モードの本番投稿許可が有効、全体停止と緊急停止が無効であることが必要。日次上限、最短投稿間隔、冪等キー、再試行、Dead Letterも従来どおり適用する。

導入時は「テスト運用」→「半自動＋承認後の本番投稿」→「自動＋自動モードの本番投稿許可」の順で切り替える。
